## Overview

OpenEmu Library Manager extends OpenEmu's built-in library with batch metadata fetching, cover art organization, ROM file deduplication, incomplete set detection, and custom collection management. It helps users with large ROM libraries maintain a clean, well-tagged database of games.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **OpenEmu Library Manager** delivers the features you need in a clean, intuitive package.

> Official website: [openemu.org](https://openemu.org)

## Key Features

| Feature | Description |
|---------|-------------|
| **Batch Metadata** | Fetch cover art and metadata for large ROM collections in bulk |
| **Deduplication** | Identify and remove duplicate ROM files across the library |
| **Set Completion** | Detect missing games in ROM sets with customizable completeness targets |
| **Custom Collections** | Organize games into custom named collections beyond system folders |
